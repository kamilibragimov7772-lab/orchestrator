# Clean install и опыт установки

Созданы четыре изолированные папки: stack/vault для minimal и full. Никакие файлы личного `~/.claude` не перезаписаны. Обе актуальные установки прошли doctor; повтор каждой установки создал 0 новых файлов. Машинный журнал — evidence/clean-install.json. Ранний прогон обнаружил ошибку относительного root в doctor; исправлена нормализацией root.resolve().

## Подтверждено

Plan не пишет файлы; существующая карточка сохраняется при конфликте; malformed settings блокирует preflight; текущие hooks и permissions не затираются; vault file/directory collision обнаруживается до записи. Пути с пробелами передаются отдельными exec args. Minimal содержит семь карточек; отсутствие остальных не считается их успешной установкой.

## Ограничения

Doctor проверяет доступность `claude`, но не вход в аккаунт и не отправку запроса. При отдельном destination хост выбирается через CLAUDE_CONFIG_DIR; настройки MCP и sign-in могут потребовать отдельной процедуры. Установщик не должен копировать credentials. Optional plugins, torch, Silero model, Remotion, Playwright и ffmpeg не скачаны этим installer. Полного офлайн-архива этих внешних зависимостей нет.

Installer атомарен по файлу, не по всей операции при внезапном сбое диска. Обновление изменённого installed tree намеренно требует свежего каталога и переноса customizations. Rollback каталога конфигурации описан в INSTALL; vault не удаляется.

Минимальная поставка — способ проверить ядро. До полноценной продуктовой установки остаётся live smoke через пользовательский путь запуска и независимая приёмка артефакта.

## Методологическая опора

- Основной фреймворк: NIST SSDF 1.1, NIST, 2022 — риск, проверка, доказательство и управление остаточным риском.
- Дополнительная модель: SLSA 1.2, 2025 — направление контроля цепочки поставки; уровень SLSA не заявляется.
- Источники: [NIST SSDF](https://csrc.nist.gov/projects/ssdf), [SLSA 1.2](https://slsa.dev/spec/v1.2/), [Claude Code hooks](https://code.claude.com/docs/en/hooks).
- Дата проверки актуальности: 2026-09-06. Оценочная шкала и веса взяты из пользовательского аудиторского брифа; баллы — экспертная оценка, не стандарт NIST.
