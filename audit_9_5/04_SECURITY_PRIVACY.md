# Security и privacy review

Основные изменения: отказ от автоматического широкого sync/export, проверка staged и outgoing history, ограниченные пути экспорта, redacted diagnostics и checked outcomes. Подробная эксплуатационная граница — [SECURITY.md](../SECURITY.md).

Gitleaks 8.30.1 получен из официального release, SHA256 проверен по опубликованным checksums. Исходная история содержит один commit; scan не нашёл находок. Рабочая копия также проверена командой `gitleaks dir . --redact=100`. Отчёты — evidence/gitleaks-*.json и текстовые результаты. Эвристический Python scanner и Gitleaks — независимые реализации, но не независимый экспертный security audit.

| Риск | Контроль | Остаток |
|---|---|---|
| Приватный файл случайно уезжает в Git | allowlist + staged/outgoing checks | Ошибка классификации человеком при изменении manifest |
| Credential удалён из последнего коммита | outgoing commit tree scan | Неизвестный/закодированный формат |
| Сбой sync разрушает работу | сохранение index, lock, FF-only | Concurrent внешние Git-операции не полностью сериализованы |
| Транскрипт попадает в общую папку | off default, явные roots, redacted/full | PII и коммерческая тайна могут остаться |
| Внешний текст управляет review | отделён от инструкций в prompt | Нет отдельной файловой изоляции model Edit |
| Опциональная модель исполняет код | доверенный источник Silero обязателен | model hash/dependency lock ещё не оформлены как release policy |

Никаких настоящих токенов в тестах не использовали. Gitleaks «0» относится к выбранным scans и версии правил. Локальный pre-commit можно обойти; решающее принуждение нужно проверять на GitHub main protection. Удалённая политика в этой сессии не менялась.

## Методологическая опора

- Основной фреймворк: NIST SSDF 1.1, NIST, 2022 — риск, проверка, доказательство и управление остаточным риском.
- Дополнительная модель: SLSA 1.2, 2025 — направление контроля цепочки поставки; уровень SLSA не заявляется.
- Источники: [NIST SSDF](https://csrc.nist.gov/projects/ssdf), [SLSA 1.2](https://slsa.dev/spec/v1.2/), [Claude Code hooks](https://code.claude.com/docs/en/hooks).
- Дата проверки актуальности: 2026-09-06. Оценочная шкала и веса взяты из пользовательского аудиторского брифа; баллы — экспертная оценка, не стандарт NIST.
