# Definition of Done (канонический источник)

> **Обязателен для каждого агента стека.** Выполняется ПОСЛЕДНИМ, перед возвратом оркестратору.
> Введён 2026-08-21 по итогам аудита 40 определений: у 26 агентов раздела приёмки не было вовсе.
> Приёмка сводилась к «я всё сделал», и оркестратор не мог отличить полный прогон от частичного.

## Правило

> **Отчёт исполнителя «готово» — не доказательство, а заявка на проверку.**

Ты закрываешь свой этап только тогда, когда каждый пункт чек-листа ниже отмечен фактом,
а не намерением. Пункт, который нечем проверить, — не «выполнен», а `[не проверено: причина]`.

## Шесть обязательных типов пунктов

Каждая карточка агента разворачивает их в свой конкретный чек-лист. Типы менять нельзя,
формулировки — под задачу.

1. **Полнота структуры.** Все заявленные в контракте выхода секции присутствуют и непусты.
   Пустой заголовок = провал пункта, а не «раздел не понадобился».

2. **Опора на факт.** Каждая оценка, находка, число и утверждение имеет якорь: цитату,
   путь с номером строки, ссылку на источник или имя проверки, которой получено.
   Утверждение без якоря вычёркивается из артефакта, а не смягчается формулировкой.

3. **Арифметика сходится.** Суммы, средние, счётчики и проценты в тексте совпадают с данными,
   на которые ссылаются, и с полями `metadata`. Если считал руками — пересчитай инструментом.

4. **Артефакт записан и путь подтверждён.** Файл создан по `output.expected_path`, повторное
   чтение возвращает содержимое, размер ненулевой. «Вывел в чат» ≠ «сохранил».

5. **Провал назван честно.** Если хоть один обязательный пункт не закрыт —
   `status: partial` плюс секция «Открытые хвосты» с формулировкой
   `- [ ] <что> — владелец: <кто> — срок: <ISO|нет>`. Ставить `ok` при незакрытом пункте запрещено.

6. **Расход возвращён.** Поле `budget_used` заполнено фактом, а не планом.
   Не зафиксировано — так и пиши `не зафиксировано`, цифру не выдумывай.

## Формат в карточке агента

```markdown
## Definition of Done

Этап закрыт, только если ВСЕ пункты отмечены фактом:

- [ ] <секции артефакта: перечислить свои> — все присутствуют и непусты
- [ ] каждая находка имеет `file:line` или цитату
- [ ] <своя арифметика: например, сумма баллов = заявленному итогу>
- [ ] файл записан по `output.expected_path`, повторный Read вернул содержимое
- [ ] незакрытые пункты вынесены в «Открытые хвосты» с владельцем, `status: partial`
- [ ] `budget_used` заполнен фактом

Провал = любой невыполненный пункт. Тогда `status: partial`, не `ok`.
```

## Почему самопроверка не отменяет ворота

Self-check ловит забытое. Он **не** ловит уверенно сделанное неправильно — на это есть
независимый ревьюер в чистом контексте (Шаг 4.1 протокола, «ворота»).
Прошедший DoD артефакт — это вход в ворота, а не выход из проверки.

Основание: Anthropic, Performance Outcomes (июнь 2026) — отдельный грейдер против рубрики
в своём контекстном окне не подвержен влиянию рассуждений исполнителя;
плюс `self-preferential bias` — модель предпочитает собственный результат.
