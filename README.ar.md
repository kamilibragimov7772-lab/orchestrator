فرعيين متخصّصين، وكل موجة تنتهي إلى ملف، ثم يقرّر مراجع مستقلّ قبول النتيجة أو ردّها.

## لماذا وُجد هذا المشروع

لا نقص في مجموعات الوكلاء الفرعيين لـ Claude Code. النقص في تلك التي **يمكن التحقّق منها**.
معظمها مجلّد من ملفات Markdown: لا شيء يثبت أن الخطّافات تعمل فعلاً، ولا شيء يثبت أن ماسح
الأسرار يقرأ البايتات الصحيحة، ولا شيء يفشل حين يتوقّف فحصٌ ما عن الفحص بصمت.

هذا المستودع يختار المقايضة المعاكسة. مكتبة الوكلاء عادية؛ **البنية التحتية المحيطة بها هي المقصد**:

| ما تقدّمه معظم المجموعات | ما يقدّمه هذا المستودع |
|---|---|
| ملفات Markdown للوكلاء فقط | وكلاء **إضافةً إلى** حرّاس ومثبّت وفاحص وبوّابة قبول ومزامنة |
| بلا اختبارات | **97 اختباراً**، بالمكتبة القياسية فقط، دون استدعاء API ودون شبكة |
| «أضف هذا إلى settings.json» | مثبّت بفحص تصادم مسبق؛ **الفاحص يشغّل الحارس فعلياً** ويشترط أن يحجب |
| يُفترض أن الخطّافات تعمل | اختبار دخان بثلاث حمولات: العادي يمرّ، السرّ يُحجب، الأمر الخطر يُحجب |
| «إنه آمن، ثق بالموجّه» | نصّ الموجّه لا يُعامل أبداً كحدّ للصلاحيات — انظر [SECURITY.md](SECURITY.md) |

كل ما يمكن لبرنامج نصّي أن يفحصه، يفحصه برنامج نصّي؛ لأن القاعدة التي تعيش في الموجّه وحده
هي قاعدة تتوقّف عن التطبيق بصمت.

## البدء السريع

يتطلّب **Python 3.10+** و**Git**. بلا مفتاح API، وبلا شبكة، وبلا استدعاء للنموذج:

```sh
git clone https://github.com/kamilibragimov7772-lab/orchestrator
cd orchestrator
python tools/verify.py
```

يشغّل هذا مدقّق عقود الوكلاء، والاختبار الذاتي لعدّاد الجاهزية، ومجموعة الاختبارات كاملة، ومسحاً
للأسرار. ولا يمسّ أي شيء خارج نسخة العمل.

ثبّت في مجلّدات تختارها بنفسك — المثبّت **يعرض الخطة أولاً ولا يستبدل شيئاً أبداً**:

```sh
python tools/install.py \
  --destination /absolute/path/stack \
  --vault /absolute/path/knowledge-base \
  --mode minimal
```

راجع الخطة ثم أعد التشغيل مع `--apply`. وإذا وُجد ملف هدف يختلف محتواه، يتوقّف التثبيت ويُبقي
ملفك كما هو. بعد ذلك تحقّق من النتيجة:

```sh
python tools/doctor.py --root /absolute/path/stack --installed
```

يثبّت `minimal` سبعة أدوار للبحث والمخرجات بصيغة Markdown. ويضيف `full` مسارات البرمجيات
وبناء المواقع والوسائط مع اعتمادياتها الخارجية. ملاحظات Windows وكيفية توجيه Claude Code إلى
المجلّد الجديد: [INSTALL.md](INSTALL.md).

|---|---|---|
| `_orchestr_protocol.md` و`agents/` و`commands/` | التوجيه والعقود وتعريف الإنجاز | المدقّق يفحص البنية؛ وجودة الإجابة تحتاج قبولاً بشرياً |
| `tools/verify.py` و`tests/` | أمر واحد قابل لإعادة الإنتاج، مع الحالات السلبية | بلا واجهة Claude وبلا MCP خارجي |
| `tools/guard.py` | كشف بيانات الاعتماد والأوامر المدمّرة عند PreToolUse | **دفاع متعمّق استدلالي** — أبقِ صلاحيات المضيف وصندوقه الرملي |
| `tools/install.py` و`tools/doctor.py` | تثبيت غير مدمّر وتقرير جاهزية | الفاحص لا يختبر المصادقة ولا جودة النموذج |
| `tools/acceptance-gate/` | فحوص حتمية لسجلّ التشغيل مع عامل مراجعة اختياري | عامل النموذج **معطّل افتراضياً**؛ والتشغيل الحيّ الكامل غير معتمد |
| `tools/sync_stack.py` | جسر Git وفق قائمة سماح دقيقة | اختياري؛ ويرفض دمج الفروع المتباعدة نيابةً عنك |
| `tools/export_session.py` | تصدير المحادثات بالاشتراك الصريح | **معطّل**؛ والحجب قائم على الأنماط وليس ضماناً للخصوصية |

### بوّابة القبول

الفكرة التي استغرقت أطول وقت حتى استقامت. بعد إغلاق أي تشغيل، يتولّى **سياق منفصل** — لم يطّلع
قط على استدلال المنسّق — تقييم المُخرَج مقابل الموجز. يعمل برنامج حتمي أولاً، ولا يحكم النموذج
إلا فيما يعجز البرنامج عن فحصه:

- `run_status` و`verdict` حقلان منفصلان. والتشغيل الذي ليس `done` يعيد *«غير خاضع للقبول»*،
  لا نجاحاً زائفاً.
- تُنتج `SKIP` نتيجة **«غير مكتمل»**، ولا تصير «مقبولاً» أبداً. ويُبلَّغ عن ملف PDF بأنه *توقيع
  فقط — افتحه في عارض*، وعن `.docx` بأن *البنية تُحلَّل، والقبول البصري منفصل*.
- رموز الخروج متمايزة: `0` مقبول · `1` مرفوض · `3` غير مكتمل · `4` غير منطبق · `2` خطأ.

المبرّر، بقياس المؤلّف على 259 تشغيلاً: القاعدة التي دخلت مدقّقاً تصمد بنسبة 76–100%؛
والقاعدة نفسها كنصّ في الموجّه تصمد بنسبة 0–39%.

## ما يمتنع عنه عمداً

الثقة في معظمها قائمة بما يرفض الأداة فعله من وراء ظهرك:

- **لا تصدير تلقائي ولا نسخ مرآة ولا دفع Git ولا cron ولا عملية نموذج عند التثبيت.** كل ذلك
  بالاشتراك الصريح ويحتاج إعداداً واضحاً.
- **لا نسخ مرآة على طريقة `robocopy /MIR`.** كان بإمكانه حذف ملفات في الوجهة غير موجودة في
  المصدر، فأُزيل.
- **لا استبدال.** الملفات المتعارضة توقف التثبيت؛ وإعداداتك وخطّافاتك تُدمج ولا تُستبدل.
- **لا نجاح صامت.** الاعتمادية المفقودة أو الفحص غير المنفَّذ يُبلَّغ عنه بـ `NOT CHECKED` أو
  `SKIP`، ولا يُعلَن نجاح لم يُستحقّ.
- **لا ادّعاء بتقييم لم يُثبَت.** كان «9.5/10» هدفاً و**لم يُعتمد** — والبنود المفتوحة مسرودة في
  [`audit_9_5/`](audit_9_5/) بدل أن تذوب في متوسّط.

## حالة التحقّق

يعمل التكامل المستمر على Windows وLinux وmacOS مع Python 3.10 و3.12، ويحلّل كل برنامج
PowerShell، ويمسح **تاريخ Git بالكامل** بأداة Gitleaks. انظر
[`.github/workflows/ci.yml`](.github/workflows/ci.yml).

حدود معلنة بصراحة، لأن الشارة الخضراء ليست دليلاً:

- تغطّي الاختبارات سلوك الأدوات، لا جودة ما يكتبه الوكلاء.
- القبول الكامل بنموذج حقيقي **غير مشمول** بمجموعة الاختبارات.
- الحرّاس استدلاليون. يكمّلون صلاحيات المضيف ولا يحلّون محلّها.
