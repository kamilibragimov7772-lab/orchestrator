# Приёмка

`checks.py RUN.md --json` проверяет закрытый run-лог и заявленные локальные артефакты.

| Exit | Значение |
|---|---|
| 0 | Детерминированные проверки прошли |
| 1 | Есть FAIL |
| 2 | Вход или вызов некорректен |
| 3 | Неполно: есть непроверенные части |
| 4 | status не done, приёмка неприменима |

Markdown frontmatter поддерживает скаляры, inline и block list; это ограниченный парсер, не весь YAML. Неоднозначность и дубли ключей отклоняются. Относительный artifact ищется от run-лога, VAULT_ROOT и CLAUDE_HOME; разные существующие совпадения — ошибка. PDF signature и неизвестные типы не подтверждают реальное открытие. Office-проверка подтверждает ZIP/XML структуру, не визуальный результат. Бюджет и Trace проверяются структурно, не сверяются с биллингом и фактическими вызовами модели.

## Worker

```sh
python tools/acceptance-gate/launch.py --vault /path/vault --dry-run
```

Рабочий запуск требует `ORCHESTRATOR_ACCEPTANCE_ENABLED=1`, авторизованный `claude` и явные `--vault`/`--stack`, если не используются установленные defaults. Он выбирает старейший done-run без приёмки в ACTIVE или ARCHIVE, ставит lock, выполняет checks, выбирает карточку из заданного `CLAUDE_CONFIG_DIR` через `--agent` и передаёт длинный бриф через stdin, ждёт процесс не более 900 секунд и проверяет поле priyomka и секцию отчёта. Stdout модели не печатается в hook log. Ошибка/timeout — failure; stale lock вручную исследуют, не удаляют вслепую.

Worker работает синхронно. Хост или отдельный supervisor отвечает за background lifetime. Не используйте Start-Job из завершающегося PowerShell. Async hooks могут быть остановлены при выходе `claude -p`; автоматическая регистрация в установщике отсутствует.

Report-only задаётся инструкцией и ограниченным списком tools, **не файловым sandbox**. Edit технически может менять другие доступные файлы; для строгой изоляции нужна копия и отдельный runtime permission profile. Текущие тесты проверяют deterministic/lifecycle ветки с mock модели. Независимость контекста, авторизация, реальная запись и визуальная приёмка пока требуют live smoke. Наличие секции не доказывает качество вердикта.
