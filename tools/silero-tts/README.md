# Silero TTS — локальная русская озвучка

Родной русский без акцента, **полностью на этом компьютере**: без облака, без ключей,
без лимитов, без интернета (после того как модель уже лежит рядом).

## Что внутри

- `v4_ru.pt` — модель Silero v4 (40 МБ). **В репозиторий не входит** — скачать из официального релиза Silero и положить рядом с `gen.py` (или указать путь в переменной окружения `SILERO_MODEL`):
  `curl --ssl-no-revoke -L -o v4_ru.pt https://models.silero.ai/models/tts/ru/v4_ru.pt` (проект: github.com/snakers4/silero-models).
  Дикторы: `xenia`, `baya`, `kseniya` (жен.), `aidar`, `eugene` (муж.)
- `gen.py` — генератор

## Как пользоваться

```bash
# образцы всех женских голосов
py gen.py samples

# полная озвучка из vo_continuous.json (файл кладётся рядом)
py gen.py full xenia
```

`vo_continuous.json` — формат: `{"lines":[{"n":1,"text":"..."}, ...]}`.
Выход — `out/line-NN.wav` (48 кГц) + `out/durs.json` с длительностями.

## Важное

- **Голос по умолчанию — `xenia`** (из трёх женских звучит естественнее всего).
- Синтез идёт на GPU (torch cu128 уже стоит), 9 реплик ≈ 40 секунд.
- Silero сам ставит ударения и «ё» (`put_accent=True, put_yo=True`) — оттого и правильное русское звучание.
- Ручное ударение, если слово прочитано неверно: поставить `+` перед ударной гласной — `нов+ая`.
- `--ssl-no-revoke` в команде скачивания обязателен на Windows — иначе schannel падает на проверке отзыва сертификата.

## Почему не облако

edge-tts — механический и требует сети.
Higgsfield/ElevenLabs — живые, но там дневной лимит и **английский акцент** в русской речи.
Silero — носители языка, локально, без ограничений.
