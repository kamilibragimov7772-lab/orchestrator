# Дополнительные видеорецепты

Это адаптируемые сценарии конкретного монтажа. Проверки ядра не означают, что созданный ролик визуально принят. Render E2E, Remotion зависимости и лицензии шрифтов проверяются отдельно.

Обязательные настройки: VIDEO_WORK (отдельные промежуточные файлы), VIDEO_SOURCE (клипы), VIDEO_OUTPUT (новый .mp4). gen_remotion_data дополнительно требует REMOTION_PROJECT. ffmpeg/ffprobe выбираются через PATH или FFMPEG_BIN/FFPROBE_BIN. Некоторые титры и fonts ожидают Windows; тексты, тайминги, voice-cleaning и пресеты адаптируются под бриф.

EDL должен быть непустым, duration — положительным конечным числом. Один stem клипа должен соответствовать одному .mov/.mp4 внутри source. Отсутствие или неоднозначность — ошибка. ffmpeg failure останавливает процесс; исходная папка больше не выбирается автоматически по USERPROFILE/OneDrive. Scratch отдельный для запуска и сохраняется для диагностики; удалять его можно после просмотра результата. Не размещайте source, work и final в одной папке.

Промежуточные файлы внутри VIDEO_WORK могут перезаписываться. gen_remotion_data копирует clean_voice2.m4a в явный VIDEO_SOURCE для public-dir и не затирает существующую копию. Выбор новой финальной цели не гарантирует полной транзакционности всех промежуточных файлов.
