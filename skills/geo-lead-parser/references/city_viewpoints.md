# Города 2ГИС: slug + центр карты для `?m=lon,lat/zoom`

Формат URL: `https://2gis.ru/<slug>/search/<запрос>/?m=<lon>%2C<lat>%2F<zoom>` (zoom 11-13 = город).

> Самый надёжный способ — открыть 2gis.ru, ввести запрос, подвинуть карту и **скопировать URL из адресной строки** (там уже правильный вьюпорт). Таблица ниже — для автосборки, когда город задан словом.
