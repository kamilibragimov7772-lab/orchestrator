# /retro

Сделай ретроспективу работы со мной за указанный период. По умолчанию — 7 дней.

## Что делать

1. Если аргумент — число → последние N дней от сегодня (`currentDate` из контекста, не выдумывай).
2. Если аргумент — период (`с YYYY-MM-DD по YYYY-MM-DD`) → используй буквально.
3. Если аргумента нет → 7 дней.

4. Запусти Task → `retro-analyst` с параметрами:
   - period: <вычисленный>
   - scope: «все проекты»
   - путь сохранения: `<VAULT_ROOT>\08-Работа-Claude\_retro\<YYYY-MM-DD>_retro_<N>days.md`
   - bucket: standard

5. Когда retro-analyst закончит — прочитай результат целиком. Он короткий (фактический срез, не интерпретация).

6. Покажи мне сводку (≤300 слов):
   - Сколько сессий, сколько проектов, доминирующая тема
   - Топ-5 ёмких сессий
   - Открытые хвосты (active OpenClaw + draft)
   - Что я возможно упустил из виду (1-2 наблюдения по паттернам)

7. Спроси: нужен ли follow-up — synthesizer (полный master) / decision-analyst (memo по hot-spot) / просто закрыть.

## Параллельность

Если ретроспективный файл за тот же период уже существует (`_retro/<date>_retro_<N>days.md`) — открой его, не пересобирай. Скажи пользователю «уже собрано <дата>, обновить?».

## Примеры использования

- `/retro` → 7 дней
- `/retro 14` → 14 дней
- `/retro с 2026-04-20 по 2026-05-04` → конкретный период
- `/retro месяц` → 30 дней
