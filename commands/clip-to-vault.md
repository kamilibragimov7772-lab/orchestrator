# /clip-to-vault

Сохрани кусок текста в vault как «черновую заметку» — пользователь потом разберёт.

## Что делать

1. Аргумент:
   - Если кавыченный текст → используй его
   - Если `last` → возьми последний tool result или выделение из `<ide_selection>` тега в контексте
   - Если ничего → спроси «что клипнуть?»

2. Сегодняшняя дата `<YYYY-MM-DD>` из `currentDate`.

3. Путь: `<VAULT_ROOT>\08-Работа-Claude\_clips\<YYYY-MM-DD>.md`

4. Если файл существует — добавь блок в конец. Если нет — создай с frontmatter:

```markdown
---
type: clips
date: <YYYY-MM-DD>
purpose: черновые заметки и выписки для последующей обработки
---

# Клипы за <YYYY-MM-DD>

## <HH:MM> — <тема одной строкой>

<текст>

---

```

5. Verify: покажи пользователю «Клип сохранён: <путь>, размер файла N клипов».

## Когда применяется

- Пользователь сказал «запомни это», «прицепи в vault», «клипни» — отдельная заметка без полной сессии
- Цитата клиента / интересный фрагмент рассуждения
- Идея для будущей сессии, чтобы не забыть

## Примеры

- `/clip-to-vault "Конкурент сегодня выкатил новый прайс, минус 15% к нашему. Проверить через неделю — это распродажа или новая политика цен."`
- `/clip-to-vault last` (сохраняет последний tool result или выделение)
